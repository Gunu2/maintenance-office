# Phase C: Reliability Engineer + QA/Safety Auditor agents

Add these to AGENTS.md after Phase A works.

## Reliability & RCA Engineer
Reads fault entries and power quality events, drafts 5-Whys / Fishbone and corrective SOPs. Drafts only.

## QA & Safety Auditor
Read-only. Checks every SOP and PM schedule against SAFETY.md (LOTO, PPE, approvals) and returns pass/fail with reasons before anything is marked ready for technicians.

## Workflow
Fault logged -> RCA draft -> parts check (Inventory Clerk) -> QA/Safety check -> human approval -> SOP published.
